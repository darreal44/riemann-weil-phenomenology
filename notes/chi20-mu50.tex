\begin{abstract}
\noindent
Notebook 18 called $\chi_{-20}$ a likely kill from above: secants
still rising at $\mu=38$, already $+19\%$ over $\hat s=0.57$.
Five windows of \texttt{scan\_s.py} through $\mu=50$ give secants
$0.534\to0.547\to0.564\to0.590$. The last one is $+4\%$ over the
four-variable prediction. The $20\%$ kill is not fired. $\chi_{-23}$
remains the only clean out-of-sample death of the map.
\end{abstract}

\section{Windows}

$\hat s_4(\chi_{-20})=0.57$. Last secant $+4\%$. The rise is real
and slow ($\approx0.02$ per decade of $\mu$). A linear extrapolation
reaches the $20\%$ line only around $\mu\sim90$, which is not a
measurement.

\section{Status}
$\chi_{-20}$ is compatible with the dead map at the windows we can
run. That does not revive the map: $\chi_{-23}$ already killed it
at $-29\%$, stationary. It does retract the ``likely kill from
above'' as a second independent death. One kill stands.
