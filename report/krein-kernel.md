# The Krein kernel

Krein’s object
is not G_reg
and not m_Q.
It is the
translation
kernel on the
interval

    K(x,y) = φ(x−y),
    x,y ∈ I,  |x−y|≤L

with φ = G
restricted to
[−L,L] — the
full Weil
kernel:
G_reg + the
1/y+CST
functional
+ the atom
at ±log 2.

PD on I means
⟨K f,f⟩≥0 for
every f with
delays in I.
That pairing
*is* Q_L(f)
for even f
supported in
I, once θ
is identified
with the
autocorrelation
of f. So the
Krein kernel
of this
problem is Q̂_L
written in
delay
coordinates,
not in the
cosine ONB.

Schur (#58–#61)
is the same
operator in
the cosine
ONB. A
positive
Krein kernel
and a
positive
Schur block
are the same
statement.
χ₈, χ₄, χ₅
taken in
cosine
coordinates
are taken
as Krein
kernels on
those three
characters.
χ₃ is the
kernel that
has not been
shown PD.

The atom
makes K a
smooth piece
plus a
diagonal
when
|x−y|=log 2.
That is a
legitimate
Hilbert–
Schmidt
perturbation
plus a
finite-rank
(actually
integral
against a
curve)
term. It is
why χ(2)=−1
is harder,
not why
Krein would
be a
different
theorem.
