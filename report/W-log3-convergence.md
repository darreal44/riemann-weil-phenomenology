# Convergence on W_{log 3}

L = log 3 is fixed.
There is no sequence
L_n → log 3 in #57.
“Convergence” is
Courant on that one
space:

    λ_min(S_N) ↓ λ_min(Q̂_L) = c_L^*
    from above.

Cosines at integer n
are a few S_N
diagonals. They stay
positive (min 0.012
on χ₃). They do not
go to α_line.

Bochner is a *lower*
bound that does not
move with N:

    α_line ≤ c_L^* ≤ Q_cos

χ₅: −0.418 ≤ c_L^* ≤ 0.0435
Width 0.46, not
shrinking. Adding
terms to the series
for k(t) is already
closed (geometric
in μ^{-2(s₀+k)}).
Sampling more t
can only *lower*
α_line (inf), which
widens the sandwich
the wrong way.

So nothing in #57
converges onto
c_L^*. The
sufficient bound
misses 0; the
necessary family
does not cross 0.
W_{log 3} is a
fixed open interval
around the unknown
c_L^*, not a
limit we can take.
