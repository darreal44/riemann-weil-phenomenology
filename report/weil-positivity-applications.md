# Applications of Weil positivity

**Criterion.** Q≥0 on an admissible class ⇔ RH (or GRH for that χ). The
application is the theorem itself. This repo never reached it.

**Converse.** One admissible θ with Q(θ)<0 ⇒ a zero off the line in the
range ˆθ sees. The application is a disproof machine. No identified
negative section was found.

**Finite windows.** Q_L≥0 for one L ⇒ no off-line zero that that window
can detect (a zero-free statement of limited height and limited width).
A *take* (S_lo>0) is an attempt at that for one L. They died by μ=8.1 on
the quorum (#78–#80).

**Li.** Positivity of λ_n is the same criterion on another class.
Application: tables of λ_n as numerical RH checks. Not run here.

**Iwasawa / p-adic.** Not an application of this Q. Different positivity
(p-adic measures).

There is no engineering application. The only use of a positive take in
this lab was as a certificate that the machine still works at that L,
then as a clock for when it stops.
