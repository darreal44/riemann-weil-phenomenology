## Verdict

- L|Imax| is not the scale of ell. Ratio 0.14 → 4.6. The desert Slepian is an upper bound on c_L, not a description of -ln λ.
- L|E| is stable *inside* a character (χ₅ : 0.198; χ₂₉ : 0.082–0.095) and not across characters (factor 2.5). A universal C ≤ 0.08 would make ell ≥ C L|E| true on this table, but it is the same slack as a+b on narrow deserts. |E| does not close the hold-out.
- dim is the least bad single predictor here (χ₁₇ ~1.7, χ₂₉ ~1.3–1.6, χ₅ ~2.4–2.8) and still not absolute.

Step 1 does not falsify a lower bound with a small C. It falsifies |E| as a replacement for a+b. Step 2 (local Bernstein) is only worth it if one insists on a theorem with some C; it will not give the measured depths.
