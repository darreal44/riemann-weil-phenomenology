# Coefficient P₃

Scalar kernel of the
n=3 term, 37a1:

    c₃ = a₃ log 3 / √3
       = −3 · log 3 / √3
       = −1.903

Times the hat
matrix Θ(log 3).
On the constant
mode Θ₀₀=2(1−y/L):

    μ     y/L    c₃ Θ₀₀
   80    0.251   −2.852
   84    0.248   −2.862
   86    0.247   −2.867
  100    0.239   −2.898

P₃ on η₀ barely
moves across μ*.
The flip of
Q_{−3}=Q+P₃ is
not a jump of
the coefficient.
It is the
background Q
(after 83) sliding
by ~0.08 while
P₃ sits at −2.86
on that mode.

The ground state
is not η₀
(ℓ~20). The
matrix element
v_minᵀ P₃ v_min
is a fraction of
c₃ Θ. That
fraction can
change with μ
even if c₃ Θ₀₀
does not. We did
not ship
v_minᵀ P₃ v_min
on the star grid.
The coefficient
c₃ is constant
(a₃ never
changes). Only
Θ(log 3; L, v_min)
can move.
