# Symmetric matrices in the lab

Everything scored as a matrix is real symmetric: H_n, the 3×3 block of
A, Θ(y), Gram of the lags. Spectrum real, min-max = Courant, ‖·‖ =
spectral radius = max |λ|.

That is why ‖Θ‖≤√2 is the same as |θ(f)|≤√2 for every hat-unit f
(`theta-sqrt2-l2.md`). It is why λ_min(H_n) is monotone in n and an
upper bound for λ_min(Q̂) on the span of the first hats (Courant the
right way for a maximum, the wrong way for a cap on ‖Θ_N‖).

No new symmetric-matrix algorithm (Jacobi, QR) moves I_{[0,1]} or the
overlap count in the √2 lemma. The 3-plane scan is not a spectral
problem in v; it is a shape problem in y.

Not a campaign.
