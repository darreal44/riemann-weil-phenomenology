# Ramanujan graphs

A d-regular graph is Ramanujan if every nontrivial eigenvalue satisfies
|λ| ≤ 2√(d−1) (Alon–Boppana bound attained). LPS constructs infinitely
many via Hamilton quaternions and the Ramanujan conjecture for GL₂ over
Q (now a theorem of Deligne for weight ≥2 forms).

That is the only honest link to this lab: the same Deligne that proves
RH over finite fields feeds the bound on those graphs. It does not feed
Q̂_L on W_L and does not identify θ with an adjacency eigenvalue.

Ihara zeta of a Ramanujan graph has no zeros in a strip — a graph RH
that is exactly the Ramanujan bound. Different object from Weil
positivity on test functions.
