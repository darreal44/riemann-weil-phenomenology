# Krein / Pólya

**Krein.** A continuous
PD function on
[−A,A] extends to
a PD function on ℝ
(generally not
uniquely). The
obstruction is a
whole-line
condition. We have
the opposite data:
m_Q is known on
all of ℝ and fails
PD there. Krein
does not let us
discard the dip
and keep a PD
extension of the
restriction to a
band — an extension
of a restriction
that came from a
non-PD function
need not be PD,
and we already
own the whole-line
function.

If one *defines*
φ = m_Q |_{[-Ω,Ω]}
with Ω the PW
Nyquist of W_L
and asks whether
φ is PD on that
interval, Krein
says that is
equivalent to the
existence of some
PD extension to ℝ.
One such candidate
is m_Q itself,
which is not PD.
There may be
another extension
that is PD even
if m_Q is not.
That would mean
φ is PD on the
band while m_Q
is not on ℝ —
exactly the
“support”
question of
`bochner-extensions.md`.
Krein names it.
It does not
compute it.
Checking PD of
φ on [−Ω,Ω] is
a Toeplitz test
on that interval,
i.e. another
cosine/hat
family. #57
already ran one
and did not
kill Q.

**Pólya.**
(i) PF functions
(Pólya frequency):
variation-
diminishing
kernels; Fourier
transform PD and
more. D₂ is
Laplace, PF-like
on [0,∞). The
atom ±log 2 is
not PF.
(ii) Pólya
entire functions
(product over
zeros, order <2):
ξ is one, under
RH it is PF in
a related sense
(de Branges /
Laguerre–Pólya).
Using that here
assumes RH.

Neither Krein
nor Pólya takes
W_{log 3} with
what we have.
Krein restates
the band
question. Pólya
PF does not
apply to
m_Q = k − w₂ cos
+ C. Laguerre–
Pólya is RH.
