# T₂ on W_{log 3}

On (log 2, log 3] the
only interior prime is
2. For a character with
χ(2)≠0,

    Q_L(f) = A_L(f) − w₂ θ_f(log 2)

w₂ = χ(2) log 2 / √2.
χ₅: w₂ < 0 so −w₂ θ
*adds* when θ>0.
χ₄: χ(4)=0? wait χ_{-4}(2)=0
so T₂ is absent and the
ladder sits higher
(0.070 vs 0.044).

θ_f(log 2) is a
continuous linear form
on W_L. So T₂ is
rank-one in the
quadratic form:
a pairing
⟨f, φ₂⟩ ⟨φ₂, f⟩
up to the kernel of
the lag map, not a
compact Sonin remainder.

A lower bound on W_L
is then

    A_L(f) − |w₂| |θ_f(log 2)|

and one needs
|θ_f(log 2)| ≤ C A_L(f)
with C |w₂| < 1, or a
better comparison of
the two quadratic
forms. Galerkin cannot
produce C. An
evaluation estimate
on PW_{L/2} at one
point y=log 2 can
(Bernstein /
Plancherel). That
estimate is the
concrete missing
line for *this*
window.

Not written. Not the
class step. One point,
one prime.
