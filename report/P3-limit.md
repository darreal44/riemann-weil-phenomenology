# Limit of P₃(L)

Fix y=log 3, L→∞.
The entries of Θ(y,L):

    θ₀₀ = 2(1−y/L) → 2
    θ_nn (n≥1) → 2
    θ_{0n} ∼ sin(2π n y/L) → 0
    θ_{nm} (n≠m) → 0

So Θ(y,∞) = 2 I₃ and
vᵀ Θ v → 2.

    w₃ = χ₅(3) log 3 / √3
       = −log 3 / √3 ≈ −0.634
    P₃(∞) = 2 w₃ ≈ −1.269

Measured P₃(50) = −0.622,
about half the limit.
Same for 2:

    P₂(∞) = 2 w₂ ≈ −0.980
    P₂(50) = −0.722  (74%)

    P₂+P₃ → −2.248

A(v) at μ=50 is −1.29.
If A saturates anywhere
near −1.3 and P₂+P₃
continue toward −2.25,
**this v loses.** The
other n-bands
([9,16] = +0.12 at μ=50)
have to keep a positive
offset of order 1, or A
has to dive with them.

The limit Θ=2I is why
|P₃| must grow after
μ=50. Convergence of P₃
is not saturation: it is
a slow march toward
2w₃, like y/L→0.
