# Why −L/3

v = (4, −3, 1)/√26,
v₀² = 16/26 = 8/13 ≈ 0.615.

At μ=16, A₀₀ = −1.383
and A(v) = −0.828
≈ v₀² A₀₀ = −0.850.
The other hats are a
20% correction.

A₀₀ / L = −1.383 / 2.773
= −0.499 ≈ −1/2.
(θ₀₀(y) = 2(L−y)/L, mean
order 1, times an
O(1) archimedean density
that integrates like L/2
after the 1/y of w is
cancelled by g(0)=0.)

So

    A(v) ∼ v₀² · (−L/2)
         = −(8/13) L / 2
         = −4L/13
         ≈ −0.307 L

−L/3 was the rounded
slope (−0.307 ≈ −0.333)
read off A/L → −0.328
at μ=37. The honest
leading term is −4L/13,
and A + 4L/13 should
go to a constant (or
o(L)) rather than A+L/3.

P tracks A, so the same
v₀² (−L/2) is what P
must cancel. The gap Q
is everything that is
*not* this φ₀-diagonal
piece.
