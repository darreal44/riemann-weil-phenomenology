# Higher-order corrections

Full 37a1, prime-side Q,
NB=80:

    μ     L      ℓ₀       ℓ₀ − 4L
   62    4.13   14.46     −2.05
   74    4.30   16.82     −0.39
   80    4.38   17.37     −0.16

ℓ₀ = 4L is a first try
(the last column shrinks).
A two-point slope on
74→80 gives

    c = Δℓ/ΔL ≈ 7.0

already unstable: 62→74
had c≈13. Three points
do not fix c L + d, let
alone c L + d + e/L.

Drop-3 λ₀ = 0.09 + ε(μ)
with |ε|<0.003 on
μ=62..80. That *is* the
higher-order term of the
drop: a constant floor
plus noise below the
scan’s last digit.
Writing

    λ₀(full)      ∼ e^{−c L}
    λ₀(drop 3)    ∼ 0.09 + o(1)

the “correction” is not
a 1/L series on the
same exponential. It is
a different object
(the form with p=3
removed) that happens
to sit at 10^{-1} while
the full form sits at
10^{-8}.

No 1/L² fit is
warranted. The next
measurement that would
constrain a correction
is drop-3 at μ≫80, to
see whether 0.09 is a
true asymptote or a
pause.
