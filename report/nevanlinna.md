# Nevanlinna, after the four takes

The four locked
χ on W_{log 3}
have Q̂_L≥0
(#58,#60,#61,#63).
Krein’s set of
measures is
therefore
nonempty for
each of them
(`krein-measures.md`).

Nevanlinna
parametrises
that set when
the truncated
moment problem
is
indeterminate:
extensions
↔ Pick
functions
ω (analytic
Im ω≥0 in the
upper half
plane), via
a linear
fractional
transform
built from
the orthogonal
polynomials
of the
interval.

We do not
have those
polynomials.
We do not
know
determinate
vs
indeterminate
on this L.
Existence
is Schur,
not
Nevanlinna.

What
Nevanlinna
would add
is a label
for μ, and
a way to
ask whether
an extremal
(atomic)
extension
exists with
masses we
can write.
That is
constructive
bookkeeping
on a set
already
known to
be nonempty.
It does not
take a new
character
and it does
not move L.

χ outside
{3,4,5,8}
and L≠log 3
are not in
this set.
