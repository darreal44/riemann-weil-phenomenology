# Haynsworth

Inertia additivity (Haynsworth 1968): if T is invertible,

    In(Q) = In(T) + In(S),

where In is the triple (n₊, n₋, n₀) of positive, negative, and zero
eigenvalues. In particular Q≥0 ⇔ T≥0 and S≥0 when there is no kernel to
split the wrong way.

The lab does not count inertia. It asks for n₋=0 via proxies (ρ<1,
S_lo>0). A true Haynsworth certificate would need the true T and the
true S, i.e. T^{-1}, which is the object the proxies avoid.

Not a new count. Not RH.
