# Spin correlations and topological defects

Analogy only. “Spin” = sign of Φ(γ)·v0 on the list Γ.

## Correlations

The only large antiferromagnetic neighbor is the charged pair itself:
χ₂₉ (10.42, 11.20), C = amp_a amp_b < 0, odd singlet.
χ₁₇ (15.64, 16.27), same.

Averaged over all neighboring zeros, ⟨amp_i amp_{i+1}⟩ is ~ 0 at every
gap scale: the cloud is incoherent. There is no AFM chain. Index
separations 2, 3, 5, 8 also average to 0. Short-range singlet, not
a spin liquid.

## Defects

v0 changes sign 34 times on 54 zeros (χ₂₉) and 34 times on 49 (χ₁₇).
A function of type τ = L/2 on an interval of length ~ ω_max is allowed
~ τ ω_max / π ≈ N nodes. We have N = 33. The node count saturates the
Paley–Wiener budget. Those zeros of hat v0 are the oscillations of
the window, not extra topological charges.

The one defect that is not budget-forced is the node *inside* the
charged pair (oddness). That is the singlet. It is a point defect in
frequency, not a winding or a Chern sector.

No topological phase: no protected degeneracy, no second odd mode
on the same pair, no long-range sign order.
