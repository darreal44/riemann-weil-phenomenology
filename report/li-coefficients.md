# Li coefficients

    λ_n
      = (1/(n−1)!)
        (d/ds)^n
        [ s^{n−1} log ξ(s) ]
        |_{s=1}

Equivalently

    λ_n
      = ∑_ρ
        [ 1 − (1 − 1/ρ)^n ]

(with

RH
⇔
λ_n ≥ 0
for

n ≥ 1.

is

ξ
on

Positivity

all
λ_n

RH;
positivity

Q̂_L
for
all
L
is

RH
(Weil).
Two
