    Q₁₆(v₀(8)) = 2.17×10⁻⁴ > 0
    λ₀(16)     = 1.58×10⁻¹²

Ratio 10⁸. The frozen vector
is a positivity witness, not
a depth witness. That is
enough for “some g, Q(g)>0”.

## What does become hand-sized

Six values θ_v(log n) for
n=7,8,9,11,13,16. Each is
an elementary combination of
sin(2π k log n / log 16) and
(1 − log n / log 16). Once
those six are in a closed
interval of width 10⁻³, the
signed rest is known to
10⁻³ and beats 0.030.

That is the certificate
shape: one explicit vector
(three rationals near
(4/5, −3/5, 0)), one
archimedean number A(v)
from the Laplace series,
six prime-power terms.
No zeros, no e₁ guess.
