# Altland–Zirnbauer class of Q and of the Gram

The object is a real symmetric quadratic form on a real vector space
(even cosine window). Eigenvalues are not symmetric about zero.

## Symmetries

- T = complex conjugation. The matrix is real, T^2 = +1.
- C (particle-hole) would require a unitary U_C with
  U_C H^T U_C^{-1} = −H. Spectrum of G is ≥ 0, not ± pairs.
  No C.
- S = TC. No C ⇒ no chiral symmetry.

That is class **AI** (Wigner–Dyson orthogonal / GOE).

The same holds for the prime-side matrix of scan_s: real symmetric,
dumped v0 real.

## Index

In the tenfold way, AI is topologically trivial in d = 0 and d = 1
(Kitaev periodic table). There is no \(\mathbb Z\) or \(\mathbb Z_2\)
index to compute for this operator in the window dimension we have.
That agrees with the missing Kramers pair, the missing second odd
mode, and the missing Chern.

AII (T^2 = −1) would have required a quaternion structure we do not
have. BDI / D would have required a particle-hole that squares to
±1 and a spectrum symmetric about zero — the Gram is a covariance,
not a BdG Hamiltonian.

Flattening H = sign(G − λ_*) about a gap in the middle of the
O(1) bulk would still be AI, still trivial in 1D.

## What this fixes

The Kondo / singlet language is a dictionary for isolation of v0.
It is not an AZ topological phase. The classification says the
phase is the ordinary orthogonal class, and that is the end of the
topological inventory for Q.
