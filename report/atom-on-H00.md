# Atom on H₀₀

H₀₀ = Q(φ₀,φ₀)
     = A(φ₀) − w₂ θ₀₀(log 2)

θ₀₀(log 2)>0,
w₂ = χ(2) log 2/√2.

    χ₈ 0.311

−w₂ θ = +|w₂| θ.

to H₀₀.
