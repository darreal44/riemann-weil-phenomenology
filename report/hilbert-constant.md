# The Hilbert constant

The best constant in ∑_{n,m=1}^∞ a_n a_m/(n+m) ≤ C ‖a‖₂² is C=π (Hilbert
1908 had 2π; Schur 1911 got π; it is sharp). There is no smaller
universal C on real ℓ².

Weighted or finite-N variants change C (Hardy–Littlewood–Pólya §9,
modern refinements with weights n^α). The lab does not have a weight
that would make C<π and still dominate Off_T. Until one is written and
proved to majorise the actual kernel, the constant stays π.

Not a campaign to shave π.
