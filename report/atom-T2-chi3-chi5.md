# The atom T₂, χ₃ vs χ₅

Same arithmetic
object:

    w₂ = χ(2) log 2 / √2
    χ₃,χ₅: χ(2)=−1
    |w₂|=0.490

Same bound
(#59): |θ_f(log 2)|≤1
on this window,
so ‖T₂‖≤|w₂|=0.490.

It does not
act on the
same H.

    χ₅  λ_H=0.053  S_diag=0.042  S_lo=+0.029
    χ₃  λ_H=0.018  S_diag=0.008  S_lo=−0.009

The atom is
a rank-one-ish
update in delay
coordinates
(the diagonal
|x−y|=log 2)
and a cosine
row in the
ONB. Its
absolute size
is identical.
χ₅ has 0.042
of room after
the continuous
piece; χ₃ has
0.008. 0.490
does not have
to be subtracted
in full (θ is
not 1 on the
ground state),
but the
Neumann far
block that
carries the
atom
(ρ_far=0.50
on χ₃) is
enough to
push the
sliver
through 0.

So “same T₂”
is true as a
matrix family
and false as
a perturbation
budget. On χ₅
T₂ is a tax
the sliver
can pay. On
χ₃ it is a
tax the sliver
cannot pay,
on top of
G_reg already
having spent
most of H.

No new
arithmetic.
The Kronecker
symbol at 2
is the same
bit. The
window is
the same
window. Only
s₀ changed
the continuous
capital.
