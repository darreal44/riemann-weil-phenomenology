# Estimate of ‖B₁‖

Sections χ₃, codiagonal only:

    [32,48) 0.3958
    [32,64) 0.3973
    [16,48) 0.3973
    [32,80) 0.3973
    2 max 0.587

‖B₁‖ saturates at 0.397 as soon as the block is longer than ~16. That is
the working estimate of the essential norm of the infinite codiagonal.
The 2-max bound 0.57–0.62 has slack because a_n changes sign.

A certified 0.40 would need a proof that no later run of aligned signs
pushes the norm up. The sequence a_n is quasi-periodic in n log 2 / log
3 and does not stay aligned. That argument is not written as a take.

Not RH.
